## Verified conclusions (this turn)

1. **Baseline identity stable.** Remote `main` tip is still `d6a9ea0…`. Prior Frozen PASS remains valid **for that SHA only**.
2. **Data-plane telemetry cost (code review):** `TransportTelemetry` is Weak + explicit `snapshot()` only; no per-byte / per-record / splice / poll-path work. Hot TLS/Vision/splice path has **no** telemetry hooks (see companion audit).
3. **Mutex contention shape (code review):** `AdaptiveTcpPool::checkout` holds `Mutex<PoolState>` only for `ready.pop()` + arrival accounting; `idle_healthy()` runs **outside** the lock. `snapshot()` takes the same mutex to read dial-failure / streak / backoff / EWMA fields that live in `PoolState`; counters already live on `PoolMetrics` atomics.
4. **Atomic ordering inventory:** pure cumulative counters use `Relaxed` `fetch_add`/`load`; lifecycle gauges (`ready`/`connecting`/`in_use`/`target_ready`/`lifecycle`/`ConnectingPermit`) use `Acquire`/`Release`/`AcqRel`. **No Relaxed downgrade candidate** without a happens-before proof — keep as-is.
5. **W1–W5:** original controlled-experiment definitions exist in local design notes (`reliability-mechanisms` / W1–W5 lab table). **GitHub issue #253 body does not name W1–W5 windows** — gap recorded; do not invent PASS for production RCA.
